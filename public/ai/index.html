三步接入

  1. 拿到接口地址和密钥

    地址是 /ai 开头的那个（完整域名随订单消息一起给你），密钥是 sk- 开头的一长串。

  2. 填进客户端

    接口地址填到「自定义请求地址 / Base URL」，密钥粘进 key 那一栏，模型名照抄订单消息里给的那个。

    curl -s https://<本站域名>/ai/v1/chat/completions \ -H "Authorization: Bearer sk-你的密钥" \ -H "Content-Type: application/json" \ -d '{"model":"<模型名>","messages":[{"role":"user","content":"你好"}]}'
  3. 发一句话试试

    能回就通了。报错先对照下面这张表，表里没有的把报错原文截图发给卖家。

报错对照表

看到什么啥意思怎么办
401 Invalid token密钥不对，或者额度已经用完（用完会被自动停用）先来本页查额度，额度为 0 就再拍一单
403 no access to model模型名写错了，或者这枚密钥没开这个模型照抄订单消息里的模型名，别自己改
429 rate limit一分钟内调太多次降频，单密钥 20 次/分钟
502 upstream上游一时连不上等一分钟重试；一直这样就找卖家
404 Not Found接口地址写错了地址要带上 /ai 前缀，结尾不要多写 /v1/v1

几点提醒

额度口径1 元 = 250 万 token，输入输出合计折算；用完自动停，不自动扣费、不自动续费。
限速单密钥 20 次/分钟。别挂高并发批量跑，超了会被降速。
安全密钥就是钱，别贴群里、别发给别人、别提交到公开仓库。
用途仅限开发测试与自用，内容合规责任在使用方。
