# 一些其他东西 — 照片放这里

这个目录是 `/gallery` 页面的图片来源，通过 `public/` 原样发布（不加哈希、不压缩）。

## 加一张照片

1. 把图片放进本目录，文件名用英文/数字，例如 `2026-10-17-tokyo.jpg`
2. 在 `src/content/photos.json` 里登记一项：

```json
{
  "src": "/gallery/2026-10-17-tokyo.jpg",
  "title": "东京，下雨的那天",
  "date": "2026-10-17",
  "caption": "在便利店门口躲了二十分钟"
}
```

`title` 必填（同时作为图片的 alt 文案），`date`（YYYY-MM-DD）和 `caption` 可选。

## 建议

- **3:2 横向**。卡片按 3:2 裁切，比例接近的图不会被裁掉主体。
- 长边不超过 **1600px**，单张控制在 **500KB** 以内。
- `.jpg` 或 `.webp` 都行。
- 也可以直接用外链（`"src": "https://…"`），但外链挂了页面会显示占位卡，不如本地稳。

## 校验

`npm run validate:content` 会在构建前检查清单格式，以及每张本地图确实存在。
格式写错或在 `photos.json` 里登记了不存在的文件，会让构建失败并指出是第几张、哪个字段 —— 不会静默少一张图。
